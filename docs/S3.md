# Shared S3 object/version client

[Overview](../README.md) · [Assurance case](ASSURANCE-CASE.md) · [Contributing](../CONTRIBUTING.md)

[`s3`](../s3/client.go) is the root module's standard-library-only S3-compatible client.
It has no new module dependency, configuration loader, local spool, plaintext cache,
authorization, encryption or quota policy. Products keep those responsibilities. The
existing nested `offsite` backup client remains a separate module/API.

## API

```go
func New(Config) (*Client, error)
func (*Client) Put(context.Context, string, io.Reader, int64) (Object, error)
func (*Client) PutIfAbsent(context.Context, string, io.Reader, int64) (Object, error)
func (*Client) PutIfMatch(context.Context, string, string, io.Reader, int64) (Object, error)
func (*Client) Get(context.Context, string, string) (io.ReadCloser, Object, error)
func (*Client) Head(context.Context, string, string) (Object, error)
func (*Client) Delete(context.Context, string, string) (Object, error)
func (*Client) ListObjects(context.Context, string, string) (ObjectPage, error)
func (*Client) ListObjectVersions(context.Context, string, VersionCursor) (VersionPage, error)
func (*Client) DeleteAllVersions(context.Context, string) error
func (*Client) DeletePrefix(context.Context, string) error
```

`Config` takes `Endpoint`, `Bucket`, `Region` (default `us-east-1`), explicit `AccessKey`
and `SecretKey`, and an optional `HTTP *http.Client`. Endpoints use path-style bucket
addressing and must be HTTPS, without userinfo, query or fragment. A nil HTTP client has
a 30-second timeout; pass an appropriately bounded client/context for longer streams.
Private HTTPS origins are allowed as operator configuration. Preserve normal certificate
and hostname verification; no insecure TLS option is provided. Constructor validation
makes no request. The client is safe for concurrent calls; treat its configuration and
shared HTTP transport as immutable.

`Object` contains `Key`, `VersionID`, `Size`, `DeleteMarker`, `IsLatest`, `LastModified` and `ETag`. Sizes are
wire-object bytes, not a product's plaintext quota. `IsLatest` comes from version listings;
ordinary listings do not carry version IDs. Empty `VersionID` means the provider did not
supply one; literal `null` is a valid opaque version ID. Products requiring versioning
must check configuration/returned IDs before treating a write as durable.

`LastModified` is the provider's HTTP/XML modification time from GET, HEAD or listings.
It is zero when absent; **zero is unknown age**, never evidence that an orphan is old.
Malformed supplied times fail the operation. Product adapters own age thresholds,
claim/GC locking and whether a provider is trusted to supply usable age metadata.

`ETag` is the opaque quoted provider token from PUT/GET/HEAD/listings, empty when absent.
Do not unquote it, derive a content digest from it, or use it as a version ID. Malformed
supplied tags fail the operation. A missing tag cannot authorize a conditional replacement.

### Streaming and versions

`PutIfAbsent(ctx, key, reader, size)` adds the signed `If-None-Match: *` condition to
streaming PUT. HTTP 412 returns `ErrAlreadyExists` without overwriting the caller's
marker; other failures, including HTTP 409 conflicts, retain their failure class.
There is no HEAD-then-unconditional-PUT fallback and no automatic body replay.
**Qualify atomic conditional writes on the selected provider** before using this for
store-identity markers. The transport cannot make a provider honor a header it ignores.
The permanent marker, store-ID checks and orphan policy remain product responsibilities.

`PutIfMatch(ctx, key, etag, reader, size)` signs and sends exactly one strong quoted
`If-Match` tag. Wildcards, weak tags, lists and malformed tags are refused locally.
HTTP 412 matches `ErrPrecondition`; HTTP 404/409 remain failures. No failure triggers
replay or an unconditional fallback. Qualify the selected provider's conditional writes:
a wrong/stale tag must create no version, including after every version of the key is gone.
Products own any delayed-writer/erasure protocol, durable operation ledger and all-copy
cleanup. These wire operations alone do not establish a complete erasure fence.

PUT consumes a known-length reader and signs `UNSIGNED-PAYLOAD` over **verified HTTPS**.
It does not buffer/hash the whole upload or create a local file. It is a single S3 PUT;
provider size limits still apply. Products seal/authenticate content and validate durable
receipts/version ledgers. A supplied reader declared zero-length is probed for emptiness
before any request; a nonempty or unreadable one is refused. The caller owns the reader, which must unblock on cancellation
if its `Read` can block; HTTP cancellation cannot fix an uncooperative arbitrary reader.

GET/HEAD take `(key, versionID)`. A nonempty ID selects that exact version and must match
the returned version header; missing/mismatched metadata is failure, not a fallback to
current content. GET returns an open stream; close it. Transport errors during reading
are sanitized and never trigger automatic mid-stream replay. Product adapters implement
verified bounded caching/range serving and content integrity checks.

Keys are literal S3 key bytes: no path cleaning. Version IDs, continuation tokens and
version-ID markers are opaque; percent escapes, pluses, slashes and `null` are preserved.
Only URL-encoded **keys/key markers** are decoded, once, when the response declares it.

### Listing and erasure

`ListObjects(ctx, prefix, continuation)` returns at most 1,000 objects and an opaque
`ObjectPage.Next` (empty at end). `ListObjectVersions(ctx, prefix, cursor)` includes data
versions **and delete markers**, preserving provider order. Pass both fields of
`VersionPage.Next` (`VersionCursor{Key, VersionID}`) unchanged; zero means end. Pages are
bounded to 8 MiB, validated in full and checked against the requested literal prefix.
Malformed metadata, a non-progressing next cursor or an oversized page fails the call.
A caller following pages owns its loop/cycle bound and context deadline.

`Delete(ctx, key, versionID)` with a nonempty ID removes exactly that version or marker.
With an empty ID it sends ordinary S3 DELETE: a versioned bucket usually adds a delete
marker and **retains the old bytes**. For a policy that removes current-version bytes,
obtain the current ID with HEAD and delete that explicit ID. Products retain their own
trash/retention and all-retained-version accounting policy.

`DeleteAllVersions(ctx, key)` filters exact equality, protecting prefix neighbours.
`DeletePrefix(ctx, prefix)` accepts only a nonempty slash-terminated namespace prefix,
for example `orgs/<opaque-org-id>/att/`; nothing is inferred or normalized. Both erase
all listed data versions and markers. Fence concurrent writers first and use a context
deadline. Each bounded batch is deleted, then listing restarts: deleting a version that
was also the next-page marker cannot make later versions disappear from the walk.
A failure can leave a partial purge; retrying the operation resumes safely. Repeated
unchanged batches fail instead of looping forever. Neither function creates delete markers.

Deletion applies to the configured bucket. Object Lock, provider retention/replication and
replica copies in other destinations remain product/operator policy; this library cannot
waive them or claim that a DELETE physically erased another provider copy. An access or
retention refusal is an error, never success or a local fallback. There is no automatic
version pruning.

### Errors and retries

Use `errors.Is(err, s3.ErrNotFound)` for a missing object/version and
`errors.As(err, &s3Error)` for `*s3.Error` (`Operation`, `StatusCode`, `Retryable`, `Missing`, `AlreadyExists`, `Precondition`).
Use `errors.Is(err, s3.ErrAlreadyExists)` for a conditional create refused with HTTP 412,
and `errors.Is(err, s3.ErrPrecondition)` for an If-Match refusal with HTTP 412.
Other request/protocol failures match `ErrFailure`; bad inputs match `ErrInvalid`.
Context cancellation/deadline errors preserve `errors.Is` identity.

Bodyless reads/listings and exact-version DELETE retry transient network/429/500/502/503/504
failures at most three times with 100/200 ms context-aware backoff. PUT and ordinary
DELETE are never automatically replayed: they can create additional versions/markers.
`Retryable` describes a transient failure, **not permission to replay a write**. Caller
retry/receipt/quota policy stays in the product.

Errors carry no raw provider body/code/header, URL, key, credential or underlying transport
message. Config credential fields are excluded from JSON; config/client formatting reveals
no fields. The library emits no logs. Never log credentials separately. All redirects,
including same-origin redirects, are refused even when an HTTP client is supplied.

## Verification

`go test -race -count=1 ./s3`, and again with `GODEBUG=fips140=on`, checks streaming,
context cancellation, opaque IDs, both pagination markers, exact/prefix scope, partial
purge retries, non-progress, missing/failure classes and credential-safe errors/redirects.
SigV4 fixtures were independently generated with the existing offsite module's pinned
AWS signer v1.48.0 (`DisableURIPathEscaping=true`); the root module imports none of it.

CI's separate pinned SeaweedFS fixture verifies actual request signatures (wrong secrets
fail), conditional marker creation, provider timestamps, version IDs and 1,001-version
pagination/erasure through a verified TLS proxy.
`KY_TEST_S3_ENDPOINT` is its loopback HTTP listener; the test refuses non-loopback targets
and sends client requests only to its temporary HTTPS proxy. Supply the fixture bucket,
access key and secret in `KY_TEST_S3_BUCKET`, `KY_TEST_S3_ACCESS_KEY` and
`KY_TEST_S3_SECRET_KEY`; these are disposable credentials. An unset endpoint skips only
this optional integration test. No test targets a live object store.
